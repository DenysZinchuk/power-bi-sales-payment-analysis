# Sales & Payment Analysis | Power BI

## Project Overview

This project presents an interactive Power BI report focused on sales and payment analysis.

The report was built using Power BI Desktop and includes data transformation in Power Query, data modeling, DAX measures, interactive filtering, sales performance analysis and forecasting-related visualizations.

## Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Microsoft Excel
- Data Visualization

## Dataset

The source dataset contains sales and payment information including:

- Date
- Region
- Area
- Manager
- Customer Type
- Sales, UAH
- Payments, UAH

## Data Model

The project includes:

- Calendar table
- Customer Types dimension
- Managers dimension
- Regions dimension
- Sales & Payments fact table
- Relationships between fact and dimension tables

## Key Measures

The report includes measures for:

- Total Sales
- Total Payments
- Sales by Customer Type
- Product Share of Total Company Turnover
- Maximum Sales Amount
- Smoothed Turnover
